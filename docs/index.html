⚠️ Before importing — set these in your GarageBand song first

GarageBand imports MIDI at the song's existing tempo and ignores the file's, and a fixed-length song section truncates the import.

  • Tempo: 105 (song settings ⚙ → Tempo)
  • Key: A minor (song settings ⚙ → Key)
  • Song section: Automatic (tap + at the top-right of Tracks view → Section A → Automatic) — otherwise the import is cut off at the section boundary

How to import

There is no “Open in GarageBand” for .mid files — import happens inside a song:

  1. Create a song and switch to Tracks view (the mixer-style icon).
  2. Tap the Loop Browser (loop icon, top right) → Files tab → Browse items from the Files app → locate the downloaded .mid.
  3. Touch and hold the file, then drag it into the tracks area and release at bar 1.
  4. Stems only: create a Drums track first and drop the Drums (and Perc) stem directly onto that track so it lands on a drum kit.

Rebuild in Live Loops

GarageBand won't take multitrack MIDI into a Live Loops grid, but it takes audio files into cells. These are the exact WAVs the Lens played — 2 bars at 105 BPM each, so they drop into cells with no stretching and your Specs grid becomes a Live Loops grid, cell for cell.

  1. New song → Live Loops, and set the tempo to 105.
  2. Tap an empty cell in the grid.
  3. Choose Loops → Audio Files.
  4. Pick the downloaded WAV — one row per instrument, so a row's cells stay on that row.

⚠️ These WAV links download from this site, so this section needs a network connection. The MIDI downloads above do not — grab the WAVs while you're online.
